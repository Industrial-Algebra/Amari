## Release Scope Summary

### `amari-tropical`

`0.21.0` positions `amari-tropical` as an optimization-oriented semiring crate with two deliberate layers:

- float max-plus carriers (`TropicalNumber`, `TropicalMatrix`, `TropicalMultivector`)
- an arena-backed ordinal substrate below `ε₀` (`OrdinalArena`, `OrdinalId`, `CnfTerm`, `OrdinalWeight`)

Key public additions and refinements:

- `Semiring`
- `fold_oplus(...)`
- `fold_otimes(...)`
- `OrdinalArena`
- `OrdinalId`
- `CnfTerm`
- `OrdinalWeight`
- `OrdinalKind`
- `OrdinalInspection`
- `OrdinalWeightInspection`
- ordinal inspection / aggregation helpers
- ordinal examples and benchmark coverage

Scope boundary reminders:

- ordinals are intentionally restricted to those below `ε₀`
- this is not a broad transfinite arithmetic release
- `viterbi` and `polytope` remain float-specific in `0.21.0`

### `amari-dual`

`0.21.0` positions `amari-dual` as an optimization-oriented forward-mode AD crate focused on local sensitivity analysis and small hot loops.

Key public additions and refinements:

- `BranchPolicy`
- `DualNumber::{max_by_policy, min_by_policy}`
- `MultiDualNumber::variables(...)`
- `MultiDualNumber::{max_by_policy, min_by_policy}`
- `StaticMultiDual<T, const N: usize>`
- `StandardStaticMultiDual`
- `ExtendedStaticMultiDual`
- fixed-size hot-loop benchmark coverage
- optimization-facing examples and stronger validation coverage

Scope boundary reminders:

- this remains a **forward-mode** AD crate
- this release does **not** claim reverse-mode graph AD
- branch policies make tie behavior explicit rather than pretending all branch points are globally smooth
