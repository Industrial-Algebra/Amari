# Amari v0.21.0 Tropical / Dual Checklist

## Purpose

This checklist operationalizes the `0.21.0` release cycle for:

- `amari-tropical`
- `amari-dual`

The cycle is specifically aimed at making both crates more useful for compiler/interpreter optimization workloads.

---

## Release Context

- `0.20.0` — `amari-gpu` refactor
- `0.21.0` — `amari-tropical` and `amari-dual`
- `0.22.0` — `amari-cgt` and `amari-surreal`

## Deferred Beyond `0.21.0`

### `amari-tropical`

- [ ] ordinals beyond `ε₀`
- [ ] broader transfinite arithmetic layers
- [ ] large theory surface around natural/Hessenberg operations unless clearly needed
- [ ] forcing every algorithm in the crate to become fully generic over all semirings

### `amari-dual`

- [ ] reverse-mode AD
- [ ] large graph-based autodiff systems
- [ ] higher-order AD as a major standalone subsystem

### Cross-cutting

- [ ] direct redesign of `amari-surreal` based on these ideas
- [ ] a full compiler IR or optimizer framework inside Amari

---

## Notes

- The ordinal substrate is expected to inform future work, but `0.21.0` should still keep a bounded, computationally honest scope.
- The highest-value design target is practical utility for ranking, path aggregation, and heuristic tuning rather than maximal algebraic generality.
