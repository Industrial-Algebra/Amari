# Amari v0.22.0 Checklist / Milestone Tracker

## Purpose

This document is the execution checklist for the `0.22.0` release cycle focused on:

- `amari-cgt`
- `amari-surreal`

It operationalizes:

## Release Context

- `0.20.0` — `amari-gpu` refactor
- `0.21.0` — `amari-tropical` and `amari-dual` extension cycle
- `0.22.0` — `amari-cgt` and `amari-surreal`

### `0.22.0` release definition

This release is complete when:

- `amari-cgt` is a usable short-game engine
- `amari-surreal` is a usable exact short-surreal crate over numeric games
- both crates are documented, tested, benchmarked, and integrated into the workspace
- neither crate exposes placeholder public APIs in its declared `0.22.0` scope

## Notes / Progress Log

### Current status notes
- [x] planning complete
- [x] implementation started
- [x] bounded generation utilities now exist for intentionally small exhaustive corpora
- [x] exact birthday/node-count layer generators now exist alongside bounded generators
- [x] canonical corpus metadata and counting hooks now exist for small generated corpora
- [x] enumeration-analysis report APIs now exist for exact layer growth and canonical reduction tracking
- [x] lightweight `amari-enumerative` bridge now exists for CGT growth-sequence adaptation

### Freeform notes

- Initial implementation landed for `amari-cgt` workspace scaffolding, arena-backed short games, partial comparison, outcomes, nimbers, and numeric-game detection.
- Initial implementation landed for `amari-surreal` dyadic arithmetic, simplest-number construction, and conversion from numeric short games.
- Workflow verification script was improved to parse the full publish crate list without truncation.
- Canonical corpus metadata now includes birthday buckets, reachable-node buckets, outcome counts, and impartial/numeric counting hooks.
- Exact birthday and reachable-node layer APIs now exist for both raw generation and canonical corpus generation.
- Enumeration-analysis reporting now exists for exact layers, including raw/canonical growth, canonical reduction, and per-layer numeric/impartial/outcome counts.
- `amari-enumerative` now has an opt-in `cgt-bridge` feature that adapts `amari-cgt` layer reports into enumerative growth summaries.
- Surcomplex work is now planned as a separate future crate, `amari-surcomplex`, rather than being folded into `amari-surreal` for `0.22.0`.
- Crate examples now exist for named small games, outcomes, nimbers, dyadic arithmetic, game-to-surreal conversion, and simplest-number construction.
- Release-polish validation now includes passing example builds, benchmark builds, workflow verification, and `cargo test --workspace` for the current CGT/surreal state.
- Additional runway before `0.22.0` is now being used for a completeness backlog beyond basic release readiness, tracked in `docs/roadmap/v0.22.0-cgt-surreal-completeness-backlog.md`.
- Pass A of that backlog has landed in `amari-surreal`: distinct non-dyadic division errors, checked reciprocal helpers, total ordering/sign utilities, reconstruction back into `amari-cgt`, and round-trip coverage.
- Pass B has started in `amari-cgt` with a new arena-independent `GameForm` import/export type plus arena round-trip and canonical-form export coverage.
